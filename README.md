# LCD1602 Display P1620B J1 REV:B (VHX1620 / HD44780 A02 Cyrillic ROM)

Полный драйвер и аппаратный декодер UTF-8 кириллицы для символьного дисплея **LCD1602 P1620B J1 94V0 REV:B** на чипе **VHX1620** под микроконтроллер **ESP32** (PlatformIO / Arduino IDE).

---

## 📌 Особенности модуля P1620B / VHX1620

В отличие от стандартных китайских дисплеев HD44780 A00 (без русской кодировки), данный модуль оснащен встроенной в ROM полноценной кириллической кодовой страницей (вариант A02 / CP866-like).

Для вывода русского текста **не требуется генерация пользовательских символов (`createChar` / CGRAM)**. Все заглавные и строчные буквы (включая **`Ё`**, **`ё`** и **`У`**) выводятся напрямую из аппаратной памяти ROM встроенной микросхемы!

## 🔌 Схема подключения к ESP32 (4-bit mode)

| Вывод LCD1602 P1620B | Вывод ESP32 | Назначение |
| :---: | :---: | :--- |
| **VSS (Pin 1)** | `GND` | Земля питания |
| **VDD (Pin 2)** | `5V` | Питание логики (+5В) |
| **VO (Pin 3)** | `GND` / Потенциометр | Регулировка контраста (при 5В подключать к GND) |
| **RS (Pin 4)** | `GPIO 19` | Выбор регистра |
| **RW (Pin 5)** | `GND` | Режим записи |
| **E (Pin 6)** | `GPIO 23` | Строб синхронизации |
| **D4 (Pin 11)** | `GPIO 18` | Данные Bit 4 |
| **D5 (Pin 12)** | `GPIO 5` | Данные Bit 5 |
| **D6 (Pin 13)** | `GPIO 4` | Данные Bit 6 |
| **D7 (Pin 14)** | `GPIO 2` | Данные Bit 7 |
| **A (Pin 15)** | `5V` | Анод подсветки |
| **K (Pin 16)** | `GND` | Катод подсветки |

## ⚡ Решение проблемы яркого контраста

1. Питание VDD дисплея обязательно должно подаваться от **5V**.
2. Для исключения мерцания и сохранения высокой контрастности не используйте `lcd.clear()` в цикле `loop()`. Используйте позиционирование каретки `lcd.setCursor(0, 0)` с перезаписью строки пробелами.
