# Состояние Проекта: Сушка (Сушильный шкаф / Дегидратор на ESP32)

> Данный файл автоматически ведется агентом и служит долговременной памятью проекта.
> При начале новой сессии агент считывает этот файл в первую очередь.

---

## 1. Описание и Назначение
- **Тип проекта**: 🔥 Прошивка (Embedded / Firmware)
- **Цель проекта**: Контроллер сушильного шкафа (дегидратора) на базе микроконтроллера ESP32 с управлением нагревателем, обдувом, датчиками температуры/влажности, экраном LCD1602 и веб-интерфейсом Settings / Wi-Fi / OTA.
- **Целевые пользователи**: Оператор сушильного шкафа (управление через энкодер/кнопки и экранное меню LCD1602, а также через веб-панель по сети).

## 2. Стек Технологий и Инструменты
- **Языки и рантайм**: C++ (Arduino Framework, ESP32)
- **Фреймворк и платформа**: PlatformIO, `espressif32 @ 6.9.0` (ESP32 Dev Module)
- **Ключевые библиотеки**:
  - `gyverlibs/GyverMenu @ ^1.1.4` — иерархическое меню на дисплее LCD1602
  - `GyverLibs/GyverTimer`, `GyverLibs/GyverButton`, `GyverLibs/GyverFilters`
  - `LiquidCrystal @ ^1.5.0` — аппаратный драйвер символьного дисплея LCD1602 (VHX1620 Cyrillic ROM)
  - `adafruit/Adafruit AHTX0 @ ^2.0.6` — датчик температуры и влажности AHT10/AHT20
  - `gyverlibs/GyverDS18` — цифровой датчик температуры DS18B20
  - `gyverlibs/Settings`, `gyverlibs/WiFiConnector`, `ArduinoOTA` — веб-интерфейс, Wi-Fi и прошивка по воздуху
- **База данных / Хранилище**: NVS Preferences / SPIFFS (`min_spiffs.csv`)
- **Система контроля версий**: Git (`https://github.com/salomanov/drying.git`, ветка `main`)

## 3. Специфика Сборки и Запуска
- **Сборка прошивки**: `pio run`
- **Прошивка по кабелю**: `pio run -t upload` (порт COM14)
- **Монитор порта**: `pio device monitor -b 115200`
- **Прошивка по воздуху**: OTA
